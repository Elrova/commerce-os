# Intégrations ELROVA

Les intégrations sont exclusivement basées sur les API officielles et leurs conditions d’utilisation.

- Les secrets restent hors du code et des fixtures.
- La base conserve seulement une `credentials_reference`.
- Le stockage est abstrait pour permettre variables d’environnement, Vercel, Supabase Vault ou un coffre dédié.
- Chaque connecteur publie ses capacités réelles et son environnement.
- Les montants estimés affichent toujours leur provenance.

Amazon France et eBay France sont prioritaires, mais aucun appel réel n’est inclus dans ce sprint.
